# 水知己微信小程序

微信开发者工具中打开本目录，项目使用正式 AppID `wx176354aa55c4c8aa`。在微信公众平台为该小程序把 `https://shuizhiji.com` 添加为 `request` 合法域名。小程序用已有的水知己账号密码登录，调用 `https://shuizhiji.com/aquora/api` 并与网页共用记录。

从开发者工具工具栏点「预览」，用有该小程序预览权限的微信扫码。照片、录音及定位在对应页面主动启用。真机使用时，在小程序后台按实际用途配置隐私指引和定位接口权限。

- 今日可以查看状态和预测详情、记一笔、查看和导出历史、拍照生成草稿，以及查询附近洗手间。
- 健康课堂提供分类、搜索、文章和原有视频。小澜助手支持聊天、语音输入、朗读、居家和外出工具。
- 个人报告支持日期范围、趋势、当日明细、AI 解读和 CSV 导出。
- 我的包含档案、校准、计划、站内提醒、外出安排、研究参与和预留设备入口。管理员账号可以打开运营后台。

照片和语音识别、朗读及 AI 解读依赖线上已启用的服务。浏览器的本地语音唤醒在小程序内使用主动录音。护理提醒在小程序内显示，微信后台订阅通知需要额外的消息模板和发送服务。

在仓库根目录用 `node --test tests/miniprogram*.test.cjs` 运行小程序测试。
